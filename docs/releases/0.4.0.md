# Ritual Checker 0.4.0

아이템의 영역 분리와 연속 화면 판독을 개선하고, 오인식 기록 기능을 추가했습니다.

- 여러 칸 아이템의 분할 후보를 함께 비교합니다. 이동 중인 컨트롤러 테두리와 보류 표시가 그림 판독에 섞이는 문제를 보완했습니다.
- 툴팁·확인창 때문에 격자 원점이 한 칸 밀리는 경우를 보정합니다. 같은 화면의 근접한 후보가 이름을 뒤집으면 실제 형태와 주변 아이템을 대조합니다.
- 검토한 실제 아이템 177종의 작은 특징 모델을 공식 참조에 보완했습니다. 게임 중 CPU에서 로컬로 실행합니다.
- 현재 시즌의 타락의 징조 제외를 리그별 출현 자료로 분리했습니다. 시세가 없다는 이유로 아이템을 제외하지 않습니다.
- **오인식 저장** 버튼을 추가했습니다. EXE 옆 `recognition-reports/`에 원본과 당시 판독을 저장합니다. 연속 판독 충돌과 직접 이름 수정도 기록하며, 오버레이와 외부 전송은 포함하지 않습니다.
- 캡처 중복 제거, 세션별 학습·검증 분리, 정답 검토 후 모델 생성과 재현 평가 도구를 추가했습니다.

원본 886장에서 중복을 묶은 641개 관측을 재분석했습니다. 별도 세션의 개발 검증 102장·아이템 관측 1,782건과 기존 회귀 46장의 검사를 통과했습니다. C# 검사 160개, Python 검사 11개, 일반/보류 전환 26쌍도 통과했습니다. 개발 자료를 이용한 결과이며 모든 아이템·환경의 정확도나 99.9999% 정확도 입증은 아닙니다.

`RitualChecker-0.4.0-win-x64.exe` 하나를 내려받아 쓰기 가능한 폴더에서 실행하세요. 기존 앱은 종료한 뒤 새 버전을 실행하세요. 설정과 시세 캐시는 유지되지만 개인 이름 수정 참조는 자료 버전 사이에 자동 이전되지 않습니다.

개발 프리릴리스입니다. 실행 파일은 Authenticode 서명되지 않았으며 SHA-256과 GitHub 빌드 출처 증명을 함께 제공합니다. 검증 범위와 성능 한계는 저장소의 `docs/VALIDATION.md`에 기록했습니다.
