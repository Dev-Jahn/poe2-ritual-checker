# 0.2.2

환율 캐시가 30분을 넘으면 환산을 중단해 작은 가격도 `0.0x div`로 표시되던 문제를 수정했습니다.

- 마지막 가격과 함께 받은 환율로 묶음 가격을 표시합니다. 반올림 전 값이 1 div 미만이면 ex, 이상이면 div입니다.
- 오래된 값은 `12.5 ex*`처럼 별표만 붙입니다. 확인 시각과 사용한 환율은 상세 정보에 표시합니다.
- poe.ninja 시세의 3시간 사용 제한과 시간에 따른 DB 삭제를 없앴습니다. 갱신이 실패하거나 재실행해도 이전 값을 사용합니다.
- 환율이 빠진 새 응답은 기존 환율을 지우지 않습니다. 환율을 한 번도 확보하지 못했다면 원래 통화를 표시합니다.
- 작은 양수 가격이 `0`으로 보이는 반올림도 수정했습니다.

C# 69개·Python 3개 검사를 통과했습니다. 오래된 실제 캐시로 화면 재생과 단일 EXE 실행을 확인했습니다. 영상 인식 변경은 없습니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
