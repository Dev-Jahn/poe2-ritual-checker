# 0.2.0

시세를 화면 분석 전에 준비하는 방식으로 변경했습니다.

- poe.ninja 커런시 14개·고유/서판 9개 분류를 실행 시 선조회하고 30분마다 갱신합니다. 디스크 캐시와 ETag를 재사용합니다.
- 캡처와 자동 툴팁 판독에서는 외부 시세 요청을 하지 않습니다. Sacred Bloom 가격도 연결했습니다.
- 거래소 검색은 안정된 고유 툴팁에서 F9 또는 LB+RB+오른쪽 스틱 누르기로만 실행합니다. 기존 옵션/매물 캐시 기능은 유지합니다.
- 동일 이름의 여러 장비 변형은 표본이 가장 많은 변형을 대표값으로 쓰고 ≈ 표시와 기준을 제공합니다.
- 의식 창 닫힘 시 Windows 캡처 세션도 종료해 노란 테두리가 남는 경로를 수정했습니다.

개발 캡처 38장·526건 회귀 검사 오류 0건. 캡처에 등장한 112종 모두 현재 poe.ninja 가격을 연결했으며 일부는 변형 미확인 대표값입니다. 이는 독립 정확도 검증이나 모든 카탈로그 항목의 시세 보장이 아닙니다. 실제 게임 종료 동작은 별도 실전 검증 범위입니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
