# 0.1.0

첫 공개 개발 프리릴리스입니다.

- 한국어 컨트롤러 의식 화면 인식, 아이템별 묶음 가격 오버레이.
- PoE2Scout 커런시와 거래소 고유 호가 조회, 로컬 캐시와 서버 대기 처리.
- 툴팁 옵션/공물 판독, 의식 영역 확대 미리보기, 원본 캡처 자동 수집.
- .NET 런타임·인식 자료를 포함한 Windows x64 단일 EXE. 별도 DLL 폴더 불필요.

EXE와 SHA256SUMS.txt를 제공합니다. EXE는 코드 서명되지 않았으며 GitHub Actions 빌드 출처 증명은 별도로 확인할 수 있습니다.

개발 캡처 38장·아이템 관측 526건의 정의된 회귀 검사를 통과했습니다. 독립 정확도 입증은 아닙니다. HDR·전체 지원 환경과 성능 목표는 미검증입니다.

실행 폴더의 captures에 게임 원본을 자동 저장합니다. 외부 공유 전 개인 정보가 화면에 있는지 확인하세요. 가격은 체결가가 아닌 시세 관측/매물 호가입니다.
