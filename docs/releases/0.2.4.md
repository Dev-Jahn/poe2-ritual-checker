# 0.2.4

‘보류 실패: 아이템 값이 너무 낮아 다시 보류할 수 없습니다’ 안내가 뜨면 의식 창을 닫은 것으로 판단해 분석이 종료되던 문제를 수정했습니다.

- 상단 정보가 가려져도 하단 ‘아이템 보류’ 문구와 격자 무늬를 함께 확인해 분석을 유지합니다.
- 같은 화면에서 보류 모드도 유지해 비용 판독 기준이 구매 모드로 바뀌지 않게 했습니다.
- 실제 창 닫힘은 기존처럼 연속 두 프레임에서 확인한 뒤 캡처를 종료합니다.

실패 원본을 포함한 개발 캡처 39장 회귀 검사와 별도의 창 상태 캡처 30장 검사를 통과했습니다. C# 77개·Python 3개 검사도 통과했습니다. 새 실패 화면의 검증 범위는 창 상태·격자 위치·보류 모드이며, 실제 게임에서 실패 메시지를 반복 발생시키는 조작은 미검증입니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
