# 0.3.1

초버 차버의 툴팁 이름을 OCR이 ‘초버 자비’로 읽으면 아이템을 연결하지 못해 수동 거래소 검색이 시작되지 않던 문제를 수정했습니다.

- 선택된 아이템 그림의 신뢰도·크기를 확인하고, 한글 자모로 비교한 이름 후보가 명확하며 옵션 세 개 이상이 일치할 때 이름 오독을 보완합니다. 선택 근거가 없거나 다른 이름과 구별할 수 없으면 확정하지 않습니다.
- 초버 차버의 소환수 스킬 레벨 사전을 +2–3으로 정정했습니다. +2와 +3 매물은 같은 옵션 시세로 섞지 않습니다. 이전 +1이나 범위 밖 수치는 판독 불완전으로 남깁니다.
- 카탈로그 갱신 도구에도 정정 자료를 적용합니다. 원본 옵션 구조가 달라지면 다시 검토하도록 갱신을 중단합니다.

첨부 화면에서 이름, 옵션 6개, 구매 공물 1,215점, 선택된 2:4 위치 연결을 확인했습니다. 모의 거래소 응답으로 영문 이름 검색과 옵션별 호가 계산을 검사했습니다. 실제 거래 서버의 접근 허용이나 응답 시간은 이 검사의 범위가 아닙니다.

기존 캡처 46장·아이템 641건 회귀 검사, C# 106개·Python 4개 검사를 통과했습니다. 독립 정확도 시험은 아닙니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
