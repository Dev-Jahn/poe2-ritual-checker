# 0.3.2

의식 징조의 수량 숫자를 읽지 못하면 가격 대신 `?개`가 표시되던 문제를 수정했습니다. 징조는 의식에서 1개씩 나오므로 숫자 OCR 없이 수량 1로 가격을 계산합니다. 흑백·보류 상태에도 같은 규칙을 적용합니다.

- 인벤토리의 최대 중첩 수량과 의식에서의 수량을 구분합니다. 묶음 수량이 달라지는 다른 커런시는 계속 숫자를 읽습니다.
- 수량을 아는 항목만 있는 화면은 수량 OCR을 생략합니다.
- 이름을 다른 커런시로 수정할 때 이전 징조의 수량 1을 그대로 사용하지 않습니다.

최신 세션 52장 전후 비교에서 수량 미확인 82건이 0건이 됐습니다. 같은 캐시로 실행 파일을 비교해 가격 라벨 복구를 확인했습니다. 기존 46장·641건 회귀 검사와 C# 112개·Python 4개 검사도 통과했습니다. 새 세션 비교는 수량 동작 검사이며 전체 아이템 식별 정확도의 독립 검증은 아닙니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
