# 0.2.1

보류 메뉴에서 아이템을 선택할 때 의식 창이 닫혔다고 판단하던 경로를 보강했습니다.

- 제목이 가려져도 공물 표시줄 전체에서 아이콘을 찾습니다. 보류 버튼 모양과 여러 격자 칸의 무늬도 함께 확인합니다.
- 한 프레임의 감지 실패로 캡처를 종료하지 않습니다. 두 프레임 연속으로 창을 확인하지 못하면 종료합니다.
- 보류 메뉴 진입·복귀 때 툴팁 유무와 관계없이 모드를 다시 판독해 구매/보류 비용을 구분합니다.
- 감지 실패와 종료 직전의 원본 화면을 captures에 저장합니다.

추가 실물 캡처 30장(열림 29장, 닫힘 1장, 보류 화면 18장)에서 창/모드 판독 오류 0건. 기존 38장·526건의 아이템 회귀 검사와 C# 60개·Python 3개 검사를 통과했습니다. 문제의 선택 순간은 기존 기록에 없어, 제목 가림·공물 아이콘 이동·굵은 테두리는 합성 화면으로도 검사했습니다. 실제 선택 순간의 완전한 재현 검증을 대신하지는 않습니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
