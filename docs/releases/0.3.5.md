# 0.3.5

흑백 상태의 좌측 찬미의 징조를 선택하면 좌측 말소의 징조로 바뀌어 인식되던 문제를 수정했습니다. 컨트롤러 선택 화살표와 빛 번짐이 한 칸짜리 아이템의 명암 특징에 섞인 것이 원인이었습니다. 선택된 아이템은 이 부분을 형태·명암·색상 비교에서 제외합니다.

최신 세션 17장의 전후 비교에서 보고된 오인식 1건이 수정됐으며 다른 아이템 이름·영역·수량은 같습니다. 좌·우측 찬미·말소·소멸 6종을 밝음/흑백·선택/비선택 조합으로 합성 검사했습니다. 실제 말소와 소멸까지 찬미로 치환하는 규칙은 사용하지 않습니다.

기존 46장·641건·툴팁 8장 회귀 검사와 C# 138개·Python 4개 검사를 통과했습니다. 개발 자료의 회귀 검증이며 모든 징조의 독립 정확도 검증은 아닙니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
