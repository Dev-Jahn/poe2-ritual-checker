# 0.2.3

같은 아이템이 흑백으로 표시되면 가격 글씨가 회색으로 바뀌던 문제를 수정했습니다. 인식 신뢰도가 바뀔 때 가격 색상까지 바꾸던 조건이 원인이었습니다.

- 가격 글씨와 라벨 테두리 색은 묶음 가치와 환율만 따릅니다. 흑백·보류 상태나 인식 신뢰도는 색에 영향을 주지 않습니다.
- 추정 시세에도 같은 색 기준을 적용합니다. `~`는 아이템 식별 추정, `≈`는 시세 추정, `*`는 이전 가격 또는 환율 사용을 표시합니다.
- 가격·수량·환율을 모르면 중립색을 사용합니다. 불확실한 항목의 공물 효율 순위 제외 기준은 유지합니다.

C# 73개·Python 3개 검사를 통과했습니다. 같은 의식의 일반/흑백 원본 화면 2장을 동일한 캐시로 재생하고, 문제가 발생했던 라벨의 색이 일치하는지 확인했습니다. 영상 인식 변경은 없습니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
