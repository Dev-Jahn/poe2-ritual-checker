# 0.3.4

아이템 테두리와 허리띠 그림을 툴팁으로 잘못 인식해 의식 보상 대부분을 제외하던 문제를 수정했습니다. 주황색 영역을 툴팁 후보로 사용할 때 닫힌 제목 테두리와 어두운 내부도 확인합니다.

최신 관련 캡처 7장에서 6개만 남던 결과가 각각 29개 아이템 영역으로 복구됐습니다. 실제 허리띠 툴팁 2장의 이름·공물 1,065점·아이템 연결도 확인했습니다. 이 검사는 영역 누락과 툴팁 동작을 검증하며, 모든 아이템 이름의 정확도를 새로 입증하지 않습니다.

기존 46장·641건·툴팁 8장 회귀 검사와 C# 128개·Python 4개 검사를 통과했습니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
