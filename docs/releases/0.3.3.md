# 0.3.3

일반 모드와 보류 모드를 오갈 때 오버레이가 사라졌다 다시 나타나던 문제를 수정했습니다. 확인된 격자 위치를 재사용하고, 다음 분석 결과가 준비될 때까지 기존 가격을 표시합니다.

- 아이템·위치·수량이 같으면 수동 거래소 조회 가격과 판독한 옵션을 유지합니다. 구매 공물과 보류 공물은 새 모드에서 다시 읽습니다.
- 아이템 구성이 바뀌면 이전 옵션 가격을 이어 쓰지 않습니다. 내용 변경·포커스 이탈·의식 창 닫힘의 숨김 처리는 유지합니다.

실제 캡처의 모드 전환 26회를 앱에서 재생해 오버레이 숨김과 가격 공백이 없음을 확인했습니다. 기존 46장·641건 회귀 검사와 C# 120개·Python 4개 검사도 통과했습니다. 캡처 재생 및 앱 상태 검사이며 실제 게임에서 입력을 반복한 검증은 아닙니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
