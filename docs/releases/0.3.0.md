# 0.3.0

키보드/마우스 UI에서 소지품 창을 의식 격자로 잘못 선택해 분석이 시작되지 않던 문제를 수정하고, 다른 폰트의 수량과 마우스 툴팁 판독을 보강했습니다.

- 화면의 여러 격자를 검토해 의식 창을 선택합니다. 소지품만 남았을 때는 의식 창으로 인식하지 않습니다.
- 다른 폰트의 숫자 1을 읽으며, 마우스 호버의 초록 테두리로 툴팁을 아이템에 연결합니다.
- 아이템 위쪽의 작은 툴팁을 인식합니다. 공물 861을 OCR이 B61로 읽어도 61로 잘못 처리하지 않습니다.
- 앱 제목의 Controller Edition 표시와 캡처 기록의 controller-ko 고정값을 제거했습니다.

제공된 마우스 캡처 7장·아이템 관측 115건·툴팁 1건을 검사했습니다. 기존 자료를 포함한 전체 46장·641건 회귀 검사와 별도 창 상태 30장 검사를 통과했습니다. C# 93개·Python 3개 검사도 통과했습니다.

마우스 검증은 한 사용자의 2560×1440 화면과 해당 폰트에 한정됩니다. 마우스 고유 툴팁, 다른 툴팁 배치, 여러 개 묶음의 새 폰트 판독, 친구 PC의 실전 성능은 미검증입니다.

Windows x64 단일 EXE, SHA256SUMS.txt, GitHub 빌드 출처 증명을 제공합니다. Authenticode 서명은 포함하지 않습니다.
