# Publication review

공개 대상은 Git 추적 파일과 릴리스용 허용 목록입니다. 작업 디렉터리 전체를 업로드하지 않습니다.

## 제외한 자료

- 원본 게임 캡처, 사용자별 세션 데이터, 비공개 평가 정답.
- 시세 응답·판매자 기록, SQLite DB, 리그/입력 설정, 로그.
- 임시 작업, 로컬 SDK와 Python 환경, 이전 배포 폴더, 빌드 중간 결과.
- 개인 키·인증서·환경 변수 파일.

Git 커밋 작성자에는 GitHub 공개 계정명과 noreply 주소를 사용합니다. 실행 파일의 디버그 소스 경로는 `/_/src`로 치환합니다. 외부 의존성의 원래 저작권·라이선스 문구는 수정하지 않습니다.

공개 인식 자료는 카탈로그, 공식 그림, 소형 UI 조각과 이름을 확인한 아이템 조각입니다. 원본 전체 화면은 포함하지 않습니다. PNG 메타데이터와 JSON의 개인 경로를 별도로 검사합니다.

`python tools/check_publication.py`는 Git 추적 파일 전체에서 개인 경로, 대표적인 인증정보 패턴, 금지된 파일을 검사합니다. 패턴 검사로 모든 종류의 비밀을 검출한다고 보장하지 않습니다. 신규 자료를 추가할 때 내용 검토도 필요합니다.

## Anti-LLM-slop 검토 기준

AI가 작성했는지 추정하는 점수는 사용하지 않습니다. 다음 자료에서 제시한 검토 원칙을 코드·주석·문서에 적용했습니다.

- [aislop 규칙](https://github.com/scanaislop/aislop/blob/main/docs/rules.md): 불필요한 주석, 미사용 코드, 포맷 불일치, 예외/비동기 처리 등 구체적 결함을 확인합니다. 이 프로젝트에서 해당 제품의 전체 검사기를 실행한 것은 아닙니다.
- [Simon Willison: Your job is to deliver code you have proven to work](https://simonwillison.net/2025/Dec/18/code-proven-to-work/): 실행·시험 근거를 갖추고 검증 부담을 사용자에게 넘기지 않습니다.
- [GitHub Awesome Copilot: Exclude Prompt Data](https://awesome-copilot.github.com/instruction/exclude-prompt-data/): 대화 지시·개인 환경 정보가 제품 문서나 코드에 섞이지 않도록 합니다.

적용 사항:

- 중복된 과거 개발 안내를 공개 대상에서 제외하고 README와 검증 문서의 역할을 나눴습니다.
- 구현에서 읽지 않는 설정 두 개를 제거했습니다.
- C#과 Python의 압축된 문장을 포맷터로 정리하고 Python 미사용 import를 제거했습니다.
- 설정 파일 읽기의 무조건 예외 처리를 예상 가능한 파일/JSON 오류로 제한했습니다.
- 주석은 비자명한 UI 규칙·단위·동시성 이유를 남깁니다. 제한 없는 정확도/성능/지원 완료 표현은 사용하지 않습니다.
- 단일 파일 빌드 여부, 단위 검사와 비공개 캡처 회귀 검사는 따로 확인합니다. 공개 CI를 전체 인식 정확도 검사라고 부르지 않습니다.

이 검토는 코드 품질 인증이나 모든 결함이 없다는 증명이 아닙니다. UI와 영상 인식의 긴 메서드는 향후 유지보수 과제로 남아 있습니다.
